# 记高一筹 Web 设计规范

当前基准为 Web 的[流水 Demo](../../apps/web/demo.html)，视觉值以本规范和对应的 [Demo 样式](../../apps/web/src/demo.css)核对。新页面先读本文件，再读 `pages/<页面名>.md` 中明确规定的页面差异。App 使用[独立的设计规范](../app/MASTER.md)。

## 暖日金视觉

日常工作区使用暖灰底、纸白面板和深色文字。浅蜂蜜色留给结余这一眼就要读到的数字。陶土色标识主要操作和支出，灰蓝色标识收入。金额的正负、分组标题和图表标签同时说明数据含义。标题用利落的无衬线中文，图标采用一致的线性笔画。

### 跨端基础色

Web 和 App 使用同一语义。Web 在业务组件中引用下表的 CSS 变量或组件语义别名，App 按相同语义映射到自身主题。

| 语义           | Web 变量                         | 色值                              | 使用位置                               |
| -------------- | -------------------------------- | --------------------------------- | -------------------------------------- |
| 页面底色       | `--demo-background`              | `#EDE9E3`                         | 页面背景                               |
| 纸白面板       | `--demo-surface`                 | `#FCFBF8`                         | 流水、表单和图表                       |
| 主要文字       | `--demo-ink`                     | `#272421`                         | 正文、标题和结余                       |
| 次要文字       | `--demo-muted`                   | `#655D56`                         | 日期、类别、支付方式                   |
| 边界           | `--demo-border`                  | `#E1DAD2`                         | 普通细边和分隔                         |
| 弱边界         | `--demo-soft-border`             | `#ECE6E0`                         | 流水行间分隔                           |
| 次级填充       | `--demo-quiet`                   | `#F2EEE8`                         | 次级按钮、筛选和分组                   |
| 主操作与焦点   | `--demo-primary`、`--demo-focus` | `#A34230`                         | 记账、选中提示、交互焦点               |

| 支出与错误文字 | `--demo-expense`                 | `#97392B`                         | 支出金额和字段错误文字，分别配对应标签 |

| 结余表面       | 结余卡专用                       | `#FFFAF0` → `#FAF2E0` → `#F3E7CB` | 单处低饱和暖日渐变，纯色回退取中间色   |

## 布局与文字

| 项目     | 规范                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 内容宽度 | 居中，最大 `1232px`。桌面左右留白 `32px`，`1120px` 及以下降为 `24px`，`770px` 及以下降为 `16px`。                              |
| 栅格     | 桌面首行是结余和趋势，下一行是流水和分类。组间距 `18px`，`1120px` 及以下为 `14px`。`770px` 及以下依次单列显示。                |
| 窄屏     | `485px` 及以下，导航另起一行，周期与记账按钮并排，搜索占一整行。流水把分类放到金额下方，同时保留交易名称和支付方式。           |
| 字体     | 中文优先 Noto Sans SC、苹方或微软雅黑，数字沿用界面无衬线。字距为 `0`。                                                        |
| 字号     | 页面标题 `30px`，最窄布局 `24px`。面板标题 `16px`，正文 `14px`，次要标签常用 `12–13px`。结余金额桌面 `43px`，最窄布局 `34px`。 |
| 表面     | 面板圆角 `8px`，控件常用 `5–6px`，分隔线 `1px`。图表与流水结构按内容自然排布。                                                 |

金额使用人民币符号、千分位和两位小数。流水的收入示例为 `+¥320.00`，支出示例为 `−¥48.60`。金额靠右并采用等宽数字，名称可换行。结余展示收入减支出的结果，负值显示负号。长金额优先为其释放栏宽，再在已定义的字号级别内回退，保留完整数字。

## 组件与状态

| 组件       | 设计与交互                                                                                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 顶部导航   | 品牌、总览、流水、支出分类。使用真实链接与清楚的选中样式，键盘焦点可见。锚点滚动后，标题与焦点留在固定导航下方。                                                   |
| 结余卡     | 依次展示结余、期间、收入和支出。卡内「记支出」「记收入」直达对应录入状态，「记一笔」默认进支出。                                                                   |
| 流水       | 按日期倒序分组并显示当日小计。桌面一行显示名称、支付方式、分类和金额。搜索支持备注、分类或支付方式，并可与全部、支出、收入筛选叠加。                               |
| 支出走势图 | 范围可切换近 7 天和本月。纵轴标明货币单位，横轴标日期。指针、触控和键盘都能选日期，图表旁显示对应日期与金额。                                                      |
| 支出分类   | 圆环中心展示最大分类的支出占比。下方按金额降序展示各分类的名称、金额、比例和对应长度。总额、趋势与流水使用同一份数据。                                             |
| 记账弹窗   | 先选收支，再填金额、分类、支付方式和可选备注。保存、取消、关闭和 Escape 都有明确反馈。打开时焦点进金额，关闭时归还触发控件。错误显示在对应字段旁，并保留已填内容。 |
| 按钮与筛选 | 主操作用陶土色实底或轻渐变配白字。次级按钮用纸白或浅暖底。分段控件使用明确的选中形状和状态语义。遇到网络提交时显示处理中并防止重复提交。                           |
| 空态与异常 | 初次无流水时提供记账入口。筛选无结果时清楚说明并允许清除条件。加载时保留区块位置，失败时提供重试并保留已填写内容。                                                 |

## 动效与无障碍

- 页面面板依次用约 `300ms` 的轻移和淡入。图线切换范围约 `410ms`，选中点约 `175ms`。数字和阅读位置保持稳定，交互可随时开始。
- 结余光斑仅随细指针移动，离开时短暂淡出。触屏使用按压反馈。系统要求减少动态效果时，面板、图线和选中点直接显示最终状态，结余光采用静态效果。系统要求减少透明度或环境缺少模糊能力时使用实色表面。
- 普通文字至少达到 `4.5:1` 对比度，大文字至少 `3:1`，理解图表或识别控件所需的非文本信息至少 `3:1`。按渐变和玻璃叠层后的实际颜色检查。 [WCAG 2.2](https://www.w3.org/TR/WCAG22/)
- 保留可见的键盘焦点、控件名称和选中状态。图表带简短可读的描述和可访问数值，金额的收支含义通过标签与符号表达。触屏上的主要控件目标高度为 `44px`，小图标按钮的可点面积至少 `44 × 44px`。

## 验收

- 在 `320px`、`390px`、`768px` 和 `1280px` 检查布局、长金额、放大字体和换行。流水与顶部导航可完整操作，固定区域为滚动内容和焦点留出空间。
- 从总览走完记账、切换收支、校验错误、保存和回到流水。核对结余、走势图和分类随同一笔记录更新。
- 分别检查鼠标、键盘、触屏和减少动态效果状态。页面改动遵循本规范，需长期保留的页面特例写入对应 `pages/<页面名>.md`。
