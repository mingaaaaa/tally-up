# 登录页

路由 `/login`。除以下差异外沿用[主规范](../MASTER.md)。

| 项目   | 规范                                                                                                                                                                                         |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 布局   | 无顶部导航。整页暖灰底，只有一张纸白面板，在视口内水平垂直居中。面板宽度 `min(400px, 100%)`，页面左右留白 `16px`，内容超高时从顶部开始滚动。 `485px` 及以下面板内边距收为 `22px 18px 18px`。 |
| 面板头 | 品牌标识与「记高一筹」居中，其下是 `20px` 的标题和 `13px` 的次要说明。                                                                                                                       |
| 表单   | 账号、密码、验证码依次排列。密码输入框右侧是显示密码按钮，用固定的名称「显示密码」配合 `aria-pressed` 表达状态。                                                                             |
| 验证码 | 输入框右侧紧贴验证码图片，间距 `8px`，图片宽 `112px`、高度与输入框一致。点击图片换一张，下方用 `12px` 次要文字提示。验证码错误后自动换一张，清空输入并把焦点移回输入框。                     |
| 主按钮 | 「登录」占满面板内容宽度，最小高度 `40px`。提交中显示「登录中…」并禁用。                                                                                                                     |
| 说明   | 面板下方间距 `14px` 处有一行 `12px` 的次要说明文字。                                                                                                                                         |
